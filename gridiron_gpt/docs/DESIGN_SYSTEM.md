# Gridiron Cortex Design System

## Product Identity

Gridiron Cortex is the intelligence engine.

GridironGPT is an application powered by that engine.

## Interface Principles

- Data before decoration.
- Every recommendation should be explainable.
- Diagnostics should be available but secondary.
- Typography should establish clear hierarchy.
- The interface should feel like analytical software rather than a consumer fantasy sports website.
- Every major screen should help answer:
  - What happened?
  - Why did it matter?
  - What changed?
  - What should I do next?

## Visual Direction

- Dark-first interface.
- Neutral base palette.
- Semantic colors for recommendations and risk.
- Minimal decoration.
- Strong hierarchy.
- Modular components.

## Future Typography Direction

- Product/header font: technical, bold, and distinctive.
- Body font: readable and professional.
- Numeric font: monospaced or tabular for aligned stats and scores.

## Future Component Areas

- Branding header
- Pipeline status
- Signal summary
- Player scorecard
- Recommendation card
- Relationship explorer
- Engine diagnostics
