# Cortex Engine Brand Guide

## Version

Brand 1.0

## Primary Logo

Cortex Node with Cortex Engine wordmark.

## Tagline

Evidence. Intelligence. Impact.

## Primary Colors

| Color | Hex |
|--------|------|
| Navy | #13294B |
| Blue | #2F80ED |
| Cyan | #1FB6AA |
| White | #E2E8F0 |

## Typography

Primary:
- Sans-serif
- Modern geometric

## Usage

Preferred:
- Horizontal logo for documents.
- Node icon for applications.
- Stacked logo for splash screens.

Avoid:
- Stretching logos.
- Changing colors.
- Adding shadows.
- Rotating the node.
